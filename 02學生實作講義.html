套件首頁教師教案程式與學習單

02　學生實作講義

做出你的 NFC 數位名片

今天要完成一個別人用手機就能開啟的個人網頁，再把網址寫進 NFC 標籤。你只需修改三檔案範本，不必安裝 Node.js 或 npm。

第一站 想好你要介紹什麼

想像你在成果展遇見想合作的人。寫下你的身分、能提供的能力與希望交流的方向。簡介避免只寫「我很認真」，改成具體內容，例如「我擅長整理訪談資料，希望找到一起做校園服務設計的夥伴」。

  • 姓名或展示名：＿＿＿＿＿＿　職稱／身分：＿＿＿＿＿＿
  • 40 至 80 字簡介：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
  • 三個技能：＿＿＿＿＿＿、＿＿＿＿＿＿、＿＿＿＿＿＿
  • 願意公開的信箱／作品連結：＿＿＿＿＿＿＿＿＿＿＿＿
電話可留空。請只填願意公開的資料，範例信箱不是你的信箱。不要把登入密碼、學號或任何金鑰貼進程式。

第二站 找到三個檔案

解壓縮教材，打開 my-nfc-card，內有以下三檔。保留它們在同一個資料夾。

my-nfc-card/
├── index.html   個人資料、網頁結構、原生 JavaScript
├── style.css    配色、字級、排版與手機樣式
└── README.md    修改及發布說明
  1. 雙擊 index.html，確認瀏覽器看得到預設名片。
  2. 用純文字編輯器開啟同一個 index.html。不要用 Word 編輯程式。
  3. 若 Windows 沒顯示副檔名，先在檔案總管開啟「顯示副檔名」，避免誤存為 index.html.txt。

第三站 只改頂部個人資料

找到「學生編輯區」的 const profile = { ... }。只改冒號後的值。下面是示意，請修改原檔，不必把整段重複貼一次。

const profile = {
  familyName: "王",
  givenName: "小晴",
  nickname: "Sunny",
  avatar: "晴",
  title: "設計系學生 / 校園服務觀察者",
  org: "我的學校",
  bio: "我喜歡透過訪談與設計，讓校園服務更容易使用。期待與不同領域的夥伴合作。",
  phone: "",
  email: "student@example.com",
  github: "https://github.com/你的帳號",
  skills: ["訪談", "資訊設計", "專案協作"],
  website: ""
};
欄位修改規則
familyName／givenName分別填姓與名，畫面自動組合，聯絡人也用同一份資料
nickname／avatar暱稱選填；頭像用一個字或短縮寫
title／org／bio身分、單位與個人簡介；在引號內編輯
phone選填；格式如 +886912345678。台灣手機 0912… 改國際格式時去掉開頭 0，再加 +886
email自己的公開信箱；不想公開可填 ""
github完整 https:// 網址；不需要可填 ""
skills每個技能有引號，以英文逗號分隔；空陣列 [] 會沒有技能標籤
website部署前留空；取得正式網址後再填

語法小提醒：保留英文雙引號 "、逗號 ,、大括號 {}。不要用中文全形引號取代。字串中要寫英文雙引號時，使用 \"，或改用中文「」；實際換行用 \n。修改後按儲存，再回瀏覽器重新整理。

檢核 A：姓名和簡介是你自己的；至少三個技能；電話留空時不顯示電話連結；卡片底部沒有欄位格式錯誤提示。

第四站 改一點樣式並測試下載

  1. 開啟 style.css，試改頂部 --accent: #38bdf8;，例如改為 #5eead4。儲存後重新整理，觀察職稱與標籤顏色。
  2. 把瀏覽器視窗縮窄到手機寬度。確認姓名、簡介與按鈕沒有被切掉，也沒有左右捲動。
  3. 按 Tab 鍵切換焦點，應看得到焦點外框；按 Enter 或空白鍵可啟動下載按鈕。
  4. 點「下載聯絡人 .vcf」，到瀏覽器下載項目找檔案，用文字編輯器檢查內容。
BEGIN:VCARD
VERSION:3.0
N:王;小晴;;;
FN:王小晴
ORG:我的學校
TITLE:設計系學生 / 校園服務觀察者
…
END:VCARD

有填 Email 才會有 EMAIL；有填有效電話才會有 TEL。中文長行可能被折成「下一行以空白開頭」，這是格式處理。本機的 file:// 路徑不會放進聯絡人網址。手機匯入測試等上線後做。

第五站 用 GitHub 網頁上傳

  1. 登入 GitHub，建立新 repository，例如 my-nfc-card。公開 repository 適合課堂展示；請先確認你同意公開的內容。
  2. 空白 repo 選「uploading an existing file」；若已有檔案，選 Add file → Upload files。
  3. 把 my-nfc-card 內的三個檔案拖進上傳區。只拖三檔，不把整份教材上傳。
  4. 填提交訊息，例如 Create digital card，按 Commit changes。
  5. 確認 repo 的最上層直接看得到 index.html、style.css、README.md。

檢核 B：把 repository 連結交給同伴，請他指出三檔案和最近一次 commit。這條路徑不需要 Git 指令列；選修指令見 README。

第六站 發布到 Vercel

  1. 登入 Vercel。選 Add New → Project，連接 GitHub 並匯入剛才的 repo。依畫面授權必要的 repository 存取。
  2. Framework Preset：選 Other。
  3. Root Directory：選含有 index.html 的資料夾。若三檔在 repo 最上層，保留根目錄。
  4. Build Command：啟用 Override，欄位留空，跳過建置。不要填 npm run build。
  5. Output Directory：本專案沒有 public 資料夾，預設會提供根目錄檔案；如需明確指定，使用 .。不要設 dist。
  6. 點 Deploy，等狀態為 Ready；部署時間依實際情況，不保證 5 秒完成。
  7. 在專案的 Domains 找正式 Production 網址，如 https://你的專案.vercel.app。以實際可用的網域為準，不要抄範例，也不要選單次 Preview 部署網址。
  8. 把正式網址填回 index.html 的 website，更新 GitHub 同名檔案並提交到正式分支。本課以 main 為正式分支，等待新部署 Ready。
本網站不需要 package.json、環境變數、API 金鑰或 Vercel CLI。平台提供的網址要讓接收者不登入也能瀏覽。若出現登入頁，先確認正式網域，再檢查專案的 Deployment Protection。

檢核 C：用無痕視窗及另一支手機開正式網址。點 Email 連結確認收件人；有填電話才測電話。重新下載 .vcf，在手機上依提示開啟並確認加入通訊錄，檢查中文姓名、信箱、選填電話與網址。

若內建瀏覽器無法下載，從選單改用 Safari 或 Chrome 開啟。沒有相同系統的同伴時，記錄你實際測過的設備，不宣稱所有手機都支援。

第七站 把正式網址寫進 NFC

  1. 準備支援 NFC 寫入的手機及可重寫的 NDEF 標籤。開啟 wakdev 的 NFC Tools；Android 需要時先打開 NFC 功能。
  2. 選 Write → Add a record → URL / URI。
  3. 輸入完整的正式 HTTPS 網址。若 App 將 https:// 作為獨立前綴選項，避免重複輸入。
  4. 確認待寫入清單只有本次的網址記錄，按 Write，將標籤靠近手機 NFC 天線，等候成功提示。
  5. 用 Read 讀回，逐字確認網址；不要只以嗶聲當成驗收。
  6. 離開寫入介面，由同伴使用另一支相容手機感應，點開通知，確認進入你的網站。

檢核 D：請同伴從碰卡到開頁，再下載聯絡人並確認內容。課堂不做永久鎖定；標籤必須可供後續練習。設備不支援時，先用網址互測，NFC 記為「待補測」。

第八站 更新一次再驗收

修改一句簡介，提交到 GitHub 的正式分支，等待 Vercel 新部署 Ready。使用原本那張 NFC 卡重新開啟網站，確認能看見更新。正式網址不變，所以不用重寫卡片；若沒更新，先查部署與網址，再重新整理。

卡住時照這個順序找

現象先檢查下一步
卡片沒有文字profile 的英文引號及逗號F12 → Console 查看 SyntaxError，從最後修改欄位檢查
樣式不見style.css 是否同資料夾、大小寫一致確認不是 style.css.txt，且 link 的 href 沒改錯
網站 404index.html 是否位於 Root DirectoryOther、空白 Build Command、Output Directory 根目錄
手機看不到最新內容提交分支、部署 Ready、正式網域重新整理或無痕開啟
下載後沒出現在通訊錄是否有開啟 .vcf 並確認匯入改用 Safari／Chrome，檢查下載項目
NFC 失敗手機 NFC 支援／開關、天線位置、標籤可寫性移開金屬、一次只放一張標籤、Read 查內容；請教師換已知可用標籤交叉測試

繳交清單

  • □ GitHub repository 連結及正式網站網址。
  • □ 一張手機名片畫面，以及聯絡人中文匯入與 NFC 讀取的證據；遮掉不必要的個資。
  • □ 完成學習單中的測試表、問題修正及三個反思問題。
  • □ 若 NFC 尚未完成，寫明原因、已完成的網址互測與補測安排。
