套件首頁學生講義程式與學習單

01　教師教案

NFC 數位名片實作教案

以一個可使用的作品，串起資訊表達、網頁基礎、版本發布與實體互動。學生下課前能向另一位同學展示完整使用流程。

對象：大學初學者／非資工背景　｜　時間：180 分鐘含休息　｜　形式：個人作品、兩人互測

一 課程目標與成果證據

學生不必先學會完整網頁開發。課程採「先修改成功，再理解原理」：先讓每個人完成自己的內容，再從剛完成的作品解釋 HTML、CSS、JavaScript、GitHub、Vercel 與 NFC 的分工。

學生能做到可觀察的成果證據
用簡短文字表達專長與合作方向一段 40 至 80 字的個人簡介，至少三個具體技能
指出 HTML 結構、CSS 樣式、JS 互動的不同責任在導讀中各找到一個例子並說明修改結果
修改資料且保持畫面與聯絡人一致profile 修改後，網頁姓名與 .vcf 的 FN／N 相符
發布可供他人開啟的靜態網站GitHub 原始碼與無須登入的正式 HTTPS 網址
說明並完成 NFC 網址寫入另一支相容手機讀取標籤後，能開啟正確名片
以測試證據改善作品記錄至少一項問題、修正方式及重測結果

二 課前準備

教師準備

  • 提前發教材壓縮包，確認教室電腦可解壓縮、顯示副檔名，瀏覽器可下載 .vcf。
  • 先用同一套三檔案在自己的示範 repository 完成一次 Vercel 部署，測試教室網路與手機行動網路皆可開啟。
  • 準備文字編輯器、投影設備、可讀寫 NDEF 的標籤及支援 NFC 的測試手機；可每兩人一組共用設備，作品仍各自繳交。
  • 事先測試所備標籤與手機組合，準備一張已寫入的示範卡；課堂不做永久鎖定。
  • 檢查 GitHub、Vercel 帳號登入與授權流程。大量新帳號驗證可能延誤，請學生課前完成。
  • 備用方案：網路中斷先完成本機作品與學習單，發布與 NFC 另約補測；不要將未完成測試記成通過。

學生準備

攜帶可編輯檔案的電腦、手機及充電設備；備妥 GitHub、Vercel 帳號。先想好願意公開的姓名或展示名、40 至 80 字簡介、三個技能、作品連結及聯絡信箱。電話選填，示範可以使用化名與不收信的 example.com 範例。

公開資料決策：請學生先決定要讓誰看見哪些資料，再上傳。即使 repository 不公開，公開網站上的聯絡資料仍可被瀏覽。不得把密碼、API 金鑰、學號或非必要個資當成名片內容。

三 核心概念與開場示範

修改本機三個檔案 → GitHub 保存版本 → Vercel 提供 HTTPS 網頁
NFC 標籤中的網址 → 手機瀏覽器開網頁 → 點按下載 .vcf → 使用者確認匯入

教師先碰卡開啟示範名片，再下載聯絡人，但停在匯入確認畫面。接著提問：「改了自我介紹，需要重新寫卡嗎？」「沒有網路，讀到網址後能保證看到網頁嗎？」讓學生先猜，再用流程回答。

重點說明：標籤儲存一筆網址記錄；網頁檔案由 Vercel 提供。網站維持相同正式網址時，內容更新不用重寫標籤；首次開頁仍需要可連線的環境。網頁不會自動替使用者建立聯絡人。

四個檢核點的追問

  • A 本機內容：「你改的是哪個欄位？重新整理後哪裡跟著改？空電話會怎樣？」
  • B 原始碼：「repository 打開第一層看得到 index.html 嗎？這次 commit 說明了什麼？」
  • C 正式網址：「同學沒有登入你的帳號也看得到嗎？這是正式網域還是單次部署網址？」
  • D 實體測試：「用 Read 看到的網址和 Production 網址完全相同嗎？第二支手機能開嗎？」

五 不同時長與能力調整

120 分鐘精簡版：開場與概念 10 分、個人資料修改 25 分、vCard 測試 10 分、GitHub 上傳 15 分、Vercel 發布 25 分、NFC 寫入 20 分、互測繳交 15 分。課前必須完成帳號與工具準備，略過 CSS 自由改色及進階格式程式導讀。

兩次各 90 分鐘：第一次完成本機名片、CSS 與 vCard；第二次進行上傳、部署、NFC 與互測。中間作業為確認公開文案及聯絡資料。

程度較快：用語意化 HTML 新增作品連結，或在 profile 新增 portfolio 並以安全網址處理函式產生連結；不要求引入框架、資料庫或套件。程度較慢的學生先完成 profile、上線與測試，進階函式只須說出用途。

七 形成性提問與參考答案

  1. 「HTML 和 CSS 哪個負責背景色？」答案：CSS；HTML 提供內容結構。
  2. 「把電話留空，為什麼不用手動刪按鈕？」答案：JS 讀到空值後隱藏該連結，也略過 vCard 電話欄位。
  3. 「按下載就已經存進別人通訊錄嗎？」答案：尚未；要由裝置開檔並由使用者確認。
  4. 「改簡介但不改網址，需要重寫 NFC 嗎？」答案：不需要；標籤仍指向相同網站。
  5. 「GitHub 有新 commit，手機卻看舊內容，先查什麼？」答案：正式分支、Vercel 部署狀態、開啟的正式網域，再檢查快取。

八 與產業創新的連結

以「交流場合第一次見面」為使用情境，請學生觀察接收者最想完成的是看作品、寫信或儲存聯絡人，再調整文案與排序。延伸作業訪談兩位使用者，記錄他們完成任務遇到的困難，提交一項有證據支持的改版。比較紙本、網址與 NFC 的使用成本及限制，討論作品的實用價值。
