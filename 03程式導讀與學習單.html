03　程式導讀與學習單

從修改範本到理解程式

對照 index.html 與 style.css 閱讀。基礎題著重看懂資料如何流動；長行折行等格式細節列為進階閱讀，不必在第一堂背下來。

一 用同一個作品學三種語言

角色本範本例子修改後的結果
HTML 內容結構main、h1、button、nav決定哪些元素存在、誰是標題及按鈕
CSS 視覺樣式.card、--accent、max-width改變色彩、留白與不同寬度下的排版
JavaScript 資料與行為profile、textContent、addEventListener填入姓名、建立技能、回應點擊並產生檔案

導讀 A HTML 元素與屬性

<h1><span id="displayName"></span></h1>
<button type="button" id="saveContact">下載聯絡人 .vcf</button>

id 是元素的識別名稱，讓 JS 找得到目標。class 可供 CSS 選擇多個同類元素。本範本使用真正的 button，因此可透過鍵盤啟動，不需用 div 模擬按鈕。

先猜再做：把按鈕文字改成「儲存我的聯絡資料」，下載內容會變嗎？先寫預測，再實際操作。

導讀 B CSS 響應式寬度

.card {
  width: 100%;
  max-width: 400px;
  padding: 28px 24px;
}
* { box-sizing: border-box; }

卡片會配合容器縮小，最大 400px。border-box 讓 padding 和 border 算進設定寬度，有助於避免手機橫向溢出。全站有 viewport 設定，瀏覽器才會依裝置寬度呈現。背景模糊只是視覺效果，瀏覽器不支援時仍能閱讀。

操作題：把 max-width 改為 460px，分別在寬螢幕與窄螢幕觀察差異。記錄後選一個適合的值。

導讀 C 物件是資料表 陣列是清單

const profile = {
  familyName: "王",
  givenName: "小晴",
  skills: ["訪談", "資訊設計", "專案協作"]
};
const fullName = profile.familyName + profile.givenName;

profile 是物件，欄位名稱對應值；skills 是陣列，可放多個技能。程式用 + 把姓與名連起來。const 宣告變數；初學階段先專心修改資料值。

導讀 D 把資料放到畫面

document.getElementById("displayName").textContent = fullName;

先找到 id 是 displayName 的元素，再把姓名寫成純文字。本範本使用 textContent，不會把簡介中的 < 或 > 當成要執行的 HTML。技能則用 forEach 逐一建立 li，放進 ul。資料沒有來自後端，重新載入時直接讀取檔案內的 profile。

操作題：在 skills 陣列加上第四個技能，預測是否要改 HTML，再驗證。

導讀 E 連結與條件

tel: 交給電話功能，mailto: 交給郵件 App，https: 開啟網站。本範本先做基本格式檢查；有效不代表電話真的有人接或信箱真的存在，仍須人工測試。空欄位會隱藏連結，錯誤格式會在卡片底部顯示提示。

function setLink(id, href) {
  const link = byId(id);
  link.hidden = !href;
  if (href) link.href = href;
}

!href 在空字串時得到 true，代表要隱藏。使用者提供的網站只接受完整 HTTPS 網址；開新分頁的連結加上 rel="noopener noreferrer"。

二 無後端如何產生聯絡人

profile → buildVCard 產生文字 → Blob 包成檔案
→ createObjectURL 建立暫存網址 → a.download 發出下載要求 → 使用者開檔匯入

vCard 的必要資訊與文字處理

vCard 是一種有固定欄位名稱的文字交換格式，副檔名為 .vcf。本課採 3.0，包含 VERSION、FN 與 N。FN 是顯示姓名，N 用分號分隔姓、名等結構。ORG 表示單位，TITLE 表示職稱；沒提供有效電話或信箱時略過該欄。

const lines = [
  "BEGIN:VCARD",
  "VERSION:3.0",
  `N:${e(profile.familyName)};${e(profile.givenName)};;;`,
  `FN:${e(fullName)}`,
  `ORG:${e(profile.org)}`,
  `TITLE:${e(profile.title)}`
];

反引號中的 ${...} 會代入值。e 是 escapeVCard 的簡寫，將文字內的反斜線、換行、分號、逗號轉成格式允許的表示，避免使用者文字變成新的欄位或分隔符號。

本課用 UTF-8 儲存中文，欄位間以 CRLF（\r\n）分隔。進階的 foldVCardLine 以 UTF-8 位元組計算長度，超長內容接到以空白開頭的下一行。這些是檔案格式處理，與 CSS 自動換行不同。

事件 Blob 與下載

byId("saveContact").addEventListener("click", downloadVCard);
const blob = new Blob([buildVCard()], {
  type: "text/vcard;charset=utf-8"
});

addEventListener 註冊點擊事件，按下按鈕才執行下載函式。Blob 是瀏覽器記憶體中的資料包，不會把聯絡資料送到伺服器。程式建立暫存網址，讓 a 元素發出下載要求；稍後呼叫 revokeObjectURL 釋放暫存資源。a.download 是給瀏覽器的下載提示，裝置實際可能下載或交給應用程式開啟。

網頁只能提出下載／開啟要求；匯入通訊錄由作業系統與使用者確認。請用實際手機驗證，不把桌面下載成功當成手機匯入成功。

三 小挑戰

  1. 基礎：新增第四個技能，並用一句話解釋為什麼不必手動加一個 HTML 標籤。
  2. 基礎：電話清空後下載 .vcf，檢查是否還有 TEL，說明畫面和檔案為何同步。
  3. 應用：把簡介改成包含逗號或分號的句子。注意簡介本來只放在畫面；要測 vCard 跳脫，請改 org 或 title，再檢查 .vcf 中的反斜線。
  4. 進階選做：在 profile 新增 portfolio，於 nav 增加對應連結，使用 httpsURL 與 setLink 處理網址；測試空白、有效 HTTPS 及錯誤網址三種情況。

教師用參考答案

按鈕文字與 profile 姓名分開，改按鈕不會改 FN／N。正式網址改變或標籤原本寫錯時需重寫；同網址內容更新不需。NFC 讀到網址但網頁失敗，先手動輸入該網址驗證，再檢查網路、正式部署 Ready 與網域／保護設定。新增技能由 forEach 產生 li；電話畫面與檔案都依同一個 validPhone 判斷。

若作為測驗，可先不發教師參考答案段落。此學習單可列印手寫，也可將回答另存文字檔繳交。
