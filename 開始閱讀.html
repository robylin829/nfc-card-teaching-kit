產業創新實作課程　教學套件

用靜態網頁製作 NFC 數位名片

從個人介紹、網頁修改到雲端發布與 NFC 寫入，完成一件能實際交換聯絡資訊的作品。

3 小時工作坊免 Node.js 與 npmHTML CSS 原生 JavaScript
開始 HTML 互動練習試調 CSS 樣式預覽名片範本

線上閱讀可直接操作練習，不需登入。要修改自己的名片，請從 GitHub repository 選 Code → Download ZIP，解壓縮後編輯三檔案範本。

使用這份套件

  1. 教師先閱讀教師教案，準備帳號、網路、手機與 NFC 標籤。
  2. 發給學生實作講義與 my-nfc-card 資料夾，依課程節奏逐站完成。
  3. 使用程式導讀與學習單說明原理、進行互測及評量。
  4. 直接開啟名片程式範本預覽；用文字編輯器修改，存檔後重新整理。
只有 my-nfc-card 內的三個檔案是學生網站專案。教師教案、學生講義與學習單放在外層，不必上傳學生的網站。

你會拿到的成果

一張手機可閱讀的深色名片、一個正式 HTTPS 網址、一份可下載的中文聯絡人檔案，以及一張寫入網址並實際測試的 NFC 卡片。沒有相容手機或標籤的學生，可以網址互測並記錄待補的 NFC 驗收。

教材形式

可透過 GitHub Pages 在線上閱讀，也可下載整包離線使用。按 Ctrl＋P 可列印或自行另存 PDF。若單獨分享學生講義，請一併保留「教材樣式.css」與「學生互動.js」。HTML 預覽、CSS 調整與即時測驗不需網路，作答不會上傳；重新整理後會還原。列印版保留講解、任務及參考答案。程式範本使用自己的 style.css，與教材互不相依。

設計調整

保留原方案的靜態架構與三檔案限制，將個人資料集中為頂部的 profile，同步產生畫面與聯絡人。GitHub 網頁上傳為主要路徑，Git 指令列為選修。部署教學明確寫出 Other、空白 Build Command、專案根目錄，避免將「免建置」誤認為完全不必檢查設定。
